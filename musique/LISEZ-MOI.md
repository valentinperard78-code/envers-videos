# Musique

Dépose ici des morceaux **libres de droits** (mp3, wav, ogg, m4a, flac), rangés par ambiance :

| Dossier | Utilisé pour |
|---|---|
| `detente/` | arrivées, scènes calmes |
| `tension/` | clashs, disputes |
| `drame/` | twists, verdicts, teasers |
| `joie/` | solutions, happy end |
| `generique/` | générique « La Villa des Pathologies » |
| `fin/` | récap et appel à l'abonnement |

Le logiciel choisit un morceau par ambiance (toujours le même pour un épisode donné), le boucle, fait les fondus et baisse le volume sous les voix. Si un dossier est vide, il utilise sa propre musique synthétisée.

Sources gratuites possibles : la bibliothèque audio de YouTube Studio (morceaux sans attribution), Pixabay Music. Vérifie toujours la licence de chaque morceau avant de l'utiliser sur TikTok.
