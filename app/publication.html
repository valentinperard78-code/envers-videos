    🟦 Mode Buffer (actuel)

    1. Dans Buffer, ta chaîne TikTok → Posting schedule : 12:30 et 19:00 tous les jours, fuseau Europe/Paris.
    2. Crée une clé sur publish.buffer.com/settings/api et colle-la dans GitHub → Secrets sous le nom BUFFER_API_KEY.
    3. C'est tout : toutes les 6 h, le robot GitHub ajoute les épisodes suivants dans la file Buffer (10 max, offre gratuite) et Buffer les publie tout seul.

    🧭 Autre option : appli TikTok maison (brouillons)

    1. Va sur developers.tiktok.com, connecte-toi avec ton compte TikTok, puis Manage apps → Connect an app. Nom : « Villa Publisher ».
    2. Dans l'application, ajoute les produits Login Kit et Content Posting API (active « Direct Post » si tu veux le mode direct).
    3. Login Kit → plateforme Desktop → Redirect URI : http://127.0.0.1:3455/callback/
    4. Scopes : user.info.basic, video.upload, video.publish. Utilise l'onglet Sandbox et ajoute ton compte TikTok comme « target user ».
    5. Copie le Client key et le Client secret ici, puis clique « Connecter mon compte TikTok ». Accepte dans la fenêtre TikTok.
    6. Le studio affiche alors 4 secrets : colle-les dans GitHub → Settings → Secrets → Actions (« New repository secret »). Optionnel : un 5ᵉ secret NTFY_TOPIC (un nom secret, ex. villa-valentin-7k2p) et l'appli gratuite ntfy sur ton téléphone abonnée à ce nom, pour recevoir la notification « vidéo prête ».
    7. Dis-moi « active la publication » : je passe "actif": true et les vidéos partent toutes seules aux heures du calendrier.

    ⚠️ Règle TikTok : sans audit, une application ne peut publier directement qu'en privé. Le mode brouillon (par défaut) respecte cette règle : la vidéo arrive dans tes brouillons TikTok, tu reçois la notification avec le texte, tu publies en public en ~10 secondes. Maximum 5 vidéos en attente à la fois et ~15 publications par jour (limite TikTok).
